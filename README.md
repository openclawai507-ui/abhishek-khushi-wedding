# Abhishek & Khushi Wedding Invitation

A mobile-friendly, scroll-animated Indian wedding invitation for 22–23 November 2026.

Built with plain HTML, CSS, and JavaScript. No framework, build step, or backend.

## Live invitation

https://openclawai507-ui.github.io/abhishek-khushi-wedding/

## Updating the invitation

Edit `index.html` for names, schedule, and venue. Design is in `style.css` and `motion.css`; interactions are in `app.js` and `motion.js`. Media is in `assets/`.

Push changes to `main` to publish automatically through GitHub Pages. Pages uses the root folder. Keep `.nojekyll` in place.

## Local preview

Run `python3 -m http.server 8000` in this folder and open http://localhost:8000.

Music is optional. Motion respects reduced-motion preferences and can be toggled off.
